# PR #38 风险分诊：高级研究历史记录绑定

本报告是实现者侧风险分诊，不构成独立异厂商评审。变更涉及 `backend/`、`web/` 与
attestation，按 `governance/role-separation.yaml` 属高风险路径，合入前须本人完整审阅并补齐
异厂商 reviewer attestation。

## BLOCKER

无已知代码阻断项。仓库闸门与合成浏览器流程均通过。

## WARN

1. 本人点选的旧高级研究会进入后续问事模型上下文，因此可能带入旧模型偏差。实现只把它标记为
   非事实参考，不能充当自身验证；仍应以现实结果和事后复盘为准。
2. 同一出生分钟可能存在多份历史记录。页面默认绑定到同生日的当前基本盘；每次绑定替换上一条
   历史参考，但保留限长后的已确认事实。
3. 单字段存储上限仍为 1200 字。绑定时最多保留 650 字事实和 540 字历史参考，防止旧研究挤占
   问事上下文；更长资料不会完整进入运行态模型。
4. 去标识正则会省略常见联系方式、证件号与账号标识，但不是通用 DLP。用户仍不应在研究摘要中
   保存姓名、精确地址或其他不必要的身份信息。

## NOTE

- 历史页与后端都按本地出生分钟精确比对；跨人记录由绑定接口返回 422。
- 绑定仅提取白话综述、大运参考、共识参考和最多四项领域摘要；辩手过程、裁判细节与逐年结论
  不进入基本盘。
- 问事提示把已确认事实与历史参考分开注入；不可变快照分别保存 `facts` 与
  `historical_reference`，并保留研究来源、版本、内容哈希与反循环说明。
- Service Worker 壳缓存升级到 v5；私密 API 仍不进入 Cache Storage。
- 变更未触碰 `engine-paipan/`、contracts、prompts、approved rulebase 或 eval 指标。
