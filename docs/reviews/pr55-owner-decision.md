# PR#55 方向变更:产品所有者结论(2026-09-01)

Codex 交叉审查(pr55-codex-review.md)判 blocked,举 B1-B4 四例"跑题可过闸",建议**收紧**
(主题闸改 all、词表边界化、加严)。产品所有者随后明确结论:

> "尊重讨论后的结论,不要挑字眼,太死板,命理本来就不会有这么精准死板的事。"

据此**逆转收紧方向**,改为按所有者意愿**放宽**:
- 切题判断**移除精准主题关键词硬匹配**(_TOPIC_GROUPS 删除)——它既是跨模型措辞误伤的根源
  (用户实遇问题),也是 Codex B3/B4 主题字眼漏洞的载体;两个问题同因,一并根除。
- `_app_answer_relevant` 降为**极粗粗筛**:仅拦 过短 / 决策类问题里毫无方向判断也无量化锚点的
  纯空洞。是否真正切题由**三方匿名盲评**把关(命理咨询本就模糊,不宜用关键词精准裁定)。
- 结论词表剔除泛场景词(顺利/建议/适合/宜忌),保留"能否成事"的方向判断;经营锚点词去泛量化。

## 对 Codex 四反例的处置(方向变更后)
- **B1**(天气散步撒词):仍被拦——去泛结论词后回答无任何方向判断词。✓
- **B2/B3/B4**(主题字眼错配/回显一词+泛结论):**按所有者结论交盲评**,粗筛不再以关键词精准拦截。
  这是**刻意的产品决策**,非遗漏:关键词无法可靠判"录取是否回答了考核""合作缓和是否回答了回款",
  强行精准化即所有者所指的"死板"。命理硬伤闸(_app_ten_god_text_valid,十神/生克说反)保留不动。

## 验收
- 切题粗筛测试 4/4;后端回归 50/50;十神/生克矛盾闸未波及。
- 请 Codex 在"粗筛+盲评兜底"的新定位下复审(而非按旧收紧标准);对"盲评能否承接切题把关"的
  质疑属产品设计范畴,升级所有者裁定。
