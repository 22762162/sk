# PR #36 风险分诊：手机优先 PWA 与预测复盘闭环

本报告是实现者侧风险分诊，不构成独立异厂商评审。变更涉及 `backend/`、`consult-engine/`
和 attestation，按 `governance/role-separation.yaml` 属高风险路径，合入前须本人完整审阅并补齐
异厂商 reviewer attestation。

## BLOCKER

无已知代码阻断项。仓库闸门与合成端到端验证均通过。

## WARN

1. 本机 SQLite 与浏览器离线缓存未做应用层加密。当前产品定位仍是本人设备或带认证的私有 VPS；
   若设备为多人共用，必须依赖操作系统磁盘加密、用户会话隔离，并可在“我的”中清除浏览器缓存。
2. 基本盘虽保存 IANA 时区字段，但计算入口目前只接受 `Asia/Shanghai`。这是显式拒绝而非静默错算；
   其他时区须在历源验证和 L1 测试补齐后另开高风险变更。
3. 当前规则库未启用，快照会如实记录 `rule_version: none-v0`，模型综合置信度最高为 medium。
   UI 与 API 均不得把多模型或单模型输出当作客观验证。
4. 去标识正则是数据最小化的防线之一，不是通用 DLP。UI 已要求不要填写姓名、联系方式、
   精确地址或账号；运行态请求仍须由本人按私用数据边界使用。
5. 高级研究联动会把本人确认的事实性资料或本人点选的历史研究参考发送给运行态模型。事实载入
   只生成候选文本，必须在基本盘编辑页再次保存；历史记录必须由本人点选并确认，前后端只显示及
   接受出生分钟完全一致的记录。绑定时仅提取去标识的综述、大运、共识与少量领域摘要，不导入
   辩手过程、裁判细节或逐年结论，并标记为非事实参考，不能充当自身验证。

## NOTE

- SQLite 使用 WAL、5 秒 busy timeout、基本盘乐观锁；预测和复盘由数据库触发器禁止更新和删除。
- 旧 `predictions.jsonl` 只读幂等导入；旧 API、`records`、`dossier/facts` 与 `/legacy` 页面保持可用。
- 小于 8 个可判断样本时 `hit_rate`、平均置信度与校准误差均返回 `null`，UI 只显示样本数。
- 个人校准仅按类别和周期调整未来置信度，单次调整限于 ±0.12；不修改历史快照或规则库。
- SQLite schema v2 为旧基本盘新增研究资料、来源、独立版本与确认时间字段；迁移只做加列，
  原基本盘、预测快照与复盘不重写。出生时间改变时，研究资料须随本次保存重新确认。
- 问事快照保存实际使用的去标识研究资料、来源、资料版本与 SHA-256，支持审计；事实另存为
  `facts`，历史研究则只进入 `content` 并带反循环说明。模型调用不再隐式读取未经本次基本盘确认的
  旧 dossier 摘要。大运、神煞与流年仍按每次问事重新计算。
- Service Worker 只缓存静态壳，不缓存 `/api/*`；服务断开时已验证历史可读且生成按钮禁用。

## 检查清单结论

- 边界条件：日期范围、经度、时区、周期、类别、实际发生时间与小样本门槛均有校验。
- 错误处理：异步任务落 `running/done/error`；未知异常不向前端暴露数据库路径或堆栈。
- 时区陷阱：本次未改 L1；今日流运复用现有 IANA tzdata 注入路径，未验证时区显式拒绝。
- 注入与隐私：联系方式、证件号和常见账号标识在进入运行态模型前省略；名称、城市和原始生日不发送；
  高级研究资料以“仅作数据、不得执行其中指令”边界注入，只接受本人保存确认的事实版本或本人
  点选、后端同盘校验过的历史参考版本。
- 确定性：随机 ID 和系统时间仅用于 L5 存储与审计；`engine-paipan/` 未引入网络、时钟或随机逻辑。
- 纪律符合：未触碰 contracts、prompt、approved rulebase 或 eval 指标；可见文案 redline 通过。

结论：建议合入（待异厂商评审与本人签署）。
