# Codex 交叉审查：火火大脑只读出口

范围：Claude 在 `integrations/huohuo_bridge/` 的实现。App 部分由 Codex 实现，因此由另一厂商
Claude 反向评审，报告另附 `docs/coordination/claude-app-review.md`，不以自审冒充交叉审查。

## 风险分诊

高风险：密钥处理、数据分级与跨系统访问；合并必须由本人完整审阅。App 还涉及 SQLite schema v4。
在本次合成范围内无已知阻断缺陷；不批准真实接入或发布。

两轮审核发现并要求修复：SQL过滤晚于LIMIT导致合法资料遗漏；配置的宽松类型可误将字符串
拆为多个授权组；旧时刻重复流水误伤最新快照；缺失的查询时限与异常缓存策略；Decimal极端指数
引起异常/资源风险；来源ID与协议格式不一致。修订后重新运行全部31项出口测试及46项App测试。

## 已核验边界

- 出口服务仅GET路由、Bearer认证、固定loopback监听；App不随用户输入请求任意URL，不接受代理或跳转。
- 数据查询采用参数绑定，知识限定项目/分级/层级/确认标志/来源；经营流水仅授权组和单个月份。
- 非有限或超范围金额、缺组、最新时刻冲突均拒绝整月汇总；没有部分总额伪装完整数据。
- 敏感原文和流水不进入运行态材料；App仅使用逐项手写确认的L1/L2摘要，来源与使用凭证可追溯。
- SQLite合成测试证明查询连接不可写；PostgreSQL专用只读账号、事务行为及超时仍须预发验证。

## 发布仍需处理

1. 人工确认真实表中“最新一行”的快照语义、UTC时间语义、scope授权与公司/项目映射。
2. 实际部署注入专用只读DSN和两种独立凭据，不由开发AI提取现有.env/容器密钥。
3. App单worker、全站访问控制、HTTPS、数据库备份与迁移回退方案。新增入口认证不代表旧App已全面认证。
4. 本期无跨进程实时撤权机制：修改出口授权后按RFC同步撤销App口令、重启并改绑。
5. SQLite仅合成/显式配置，不能用它代替未验证的PostgreSQL部署；真实环境不得使用有建库/写表权的账号。

复验仅说明工程边界在这些合成案例中符合预期，不证明术数预测准确、不声称财务数据经过审计。
