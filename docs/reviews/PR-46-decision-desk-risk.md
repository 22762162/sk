## 已实现控制

- 个人主体独立于默认档案；切换主体/公司/项目清空旧提问背景。开始问事后输入暂时锁定。
- 公司人员需明确勾选并包含主参考人；检查公司/项目归属、授权、有效日期、重复与最多六人。
- UI 提交主体、公司、项目及相关人员版本；任何已确认版本过时均拒绝。
- 一次 SQLite 读事务冻结范围；异步调用只使用冻结资料。范围、匿名计算资料和角色别名映射
  随预测锁定，后续改档案不改旧结论。
- 公司复盘不进入个人统计或个人置信度校准。历史预测和复盘保持不可变。
- 事实记录只追加，发生日期与录入时间分别保存；已有研究需预览并确认，不能自动升级成事实。
- `SANJIAN_APP_DB` 指定替代库时不再隐式导入生产路径下旧预测。测试服务还显式替换旧档案/记录
  读取函数，并阻断旧接口和模型调用；不会为了 UI 测试加载 `.env`。
