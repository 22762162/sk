## 1. 六爻（rules: `liuyao-rules-v1`）

### 1.1 起卦输入协议（可回放）

```json
{
  "method": "manual_coins | system_random",
  "lines": [6, 7, 8, 9, 7, 8],       // 初爻→上爻;三枚硬币:背记3、字记2,三枚之和
  "cast_at": "2026-08-12T10:30:00+08:00",
  "day_ganzhi": "戊申",               // 装六神/旬空用;由排盘引擎按当前口径给出
  "month_branch": "申",               // 月建;由节气表给出
  "rules_version": "liuyao-rules-v1"
}
```

- 6=老阴(动)、7=少阳、8=少阴、9=老阳(动)。`system_random` 用 `secrets` 模拟三枚硬币，逐爻记录。
- **换日口径**：日干支取排盘引擎同一口径（含子时流派设置），版本随记录存档。

### 1.2 装卦规则（全部查表/生成，零判断）

- **八宫生成**：每宫由纯卦按 变初→变二→变三→变四→变五→(再变四)游魂→(内三爻复原)归魂 生成——
  程序生成 + 已知卦名断言双重校验，不手抄 64 行表。
- **世应**：宫内序 → 世爻位 [6,1,2,3,4,5,4,3]；应 = 世隔三位。
- **纳甲**（内/外卦地支与天干）：乾甲子寅辰/壬午申戌；坎戊寅辰午/戊申戌子；艮丙辰午申/丙戌子寅；
  震庚子寅辰/庚午申戌；巽辛丑亥酉/辛未巳卯；离己卯丑亥/己酉未巳；坤乙未巳卯/癸丑亥酉；兑丁巳卯丑/丁亥酉未。
- **六亲**：以卦宫五行为我——同我兄弟、生我父母、我生子孙、克我官鬼、我克妻财。
- **六神**：按日干起初爻——甲乙青龙、丙丁朱雀、戊勾陈、己腾蛇、庚辛白虎、壬癸玄武，向上循环。
- **动变**：6/9 为动爻，翻转成变卦；变爻纳支取变卦对应位。
- **旬空**：按日柱旬空（复用 `luck.kongwang`），标注落空之爻。
- 伏神、进退神、反吟伏吟等进阶项 → 解释层（AI 可提及，引擎 v1 不判）。

### 1.3 引擎输出

本卦/变卦名与宫、世应位、逐爻{位、阴阳、动否、纳支、五行、六亲、六神、空亡}、变爻纳支、月建日辰。

## 2. 梅花易数（rules: `meihua-rules-v1`）

- **v1 只上「报数起卦」**（完全经典、无历法依赖）：两数 n1、n2 + 起卦时辰。
  上卦 = n1 % 8（0 作 8），下卦 = n2 % 8，先天数 乾1兑2离3震4巽5坎6艮7坤8；
  动爻 = (n1 + n2 + 时辰序) % 6（0 作 6），时辰序 子1…亥12。
- **时间起卦需农历（年支序+农历月日）**，仓库暂无朔日表 → 列为 P3 决策项：
  引入朔日表（数据入库、来源标注、金测）或维持手动输入农历数字。**不得用公历数字冒充农历口径。**
- 输出：本卦、互卦（2-4 爻为下、3-5 爻为上）、变卦、体/用（动爻所在为用）、体用五行生克关系。
