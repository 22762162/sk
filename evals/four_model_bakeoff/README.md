# 四模型八字能力盲测

本目录冻结 Claude、ChatGPT、Gemini、DeepSeek 的同题评测协议。它回答两个不同问题，结论不得混用：

1. **确定性基础规则一致性**：十神、地支关系、五行计数、大运与干支历法选择题能否答对；
2. **真实问事命中率**：问题必须在结果发生前封存，并在期限结束后按预先定义的客观结果回填。

第一项可自动评分，但它的答案源自当前规则契约，只能说明模型是否稳定遵循该契约，不能证明传统术数本身的科学有效性。第二项在积累足够的封存案例前不得宣布胜者，也不得用回答长度、语气自信或事后解释代替命中。

## 冻结配置

- 参赛型号：`claude-fable-5`、`gpt-5.6-sol`、`gemini-3.1-pro-preview`、`deepseek-v4-pro`；
- 60 道语义相同的四选一题，分为十神 20、地支关系 16、五行计数 8、大运 8、干支历法 8；
- 每轮按盲标重排题目和选项，连续运行 3 轮；
- 每批 15 题，模型按轮次轮换调用顺序，降低固定位置和时段偏差；
- 主指标为精确正确率，另报分类正确率、漏答率、格式合规率、跨轮稳定率、延迟与 token 用量；
- 同分时不以文风或主观观感破同分。

具体冻结值见 `config.json`，统一作答指令见 `request-system.txt`。修改这两个文件必须与评分器改动分开提交，以遵守 INV-12。

## 真实问事评测门槛

每条案例至少包含：不可修改的创建时间、原始问题、四家盲标输出、明确的预测期限、事前写定的可观察结果与事后证据。个人身份信息和完整命盘不进入公开仓。

- 少于 30 条已到期案例：只展示案例，不排名；
- 30–99 条：只能给出“初步趋势”，同时报告置信区间和弃权表现；
- 100 条及以上：才允许报告阶段性命中率排名；
- 每次换模型版本、提示协议或评分口径，都开启新的评测世代，不与旧世代直接合并。

上线仍保持三方会审。ChatGPT 在本目录仅作为第四个实验臂，不自动加入生产链路。
