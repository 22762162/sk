# backend（FastAPI 应用层）

FastAPI 同时提供原研究接口与 `/api/app/*` 手机 App 闭环：基本盘、问事任务、不可变预测快照、
只增复盘和按类别/周期/算法/模型/规则版本统计。App 数据使用 Python 标准库 SQLite（WAL +
busy timeout + 乐观锁）；旧 `predictions.jsonl` 启动时幂等迁移，不删除或回写旧数据。

基本盘可保存本人确认的高级研究事实并独立版本化。`research-candidates` 读取旧档案中本人录入的
既成事实，并只列出与当前基本盘出生分钟一致的历史研究记录。事实须在 App 编辑页检查并保存；
历史研究须由本人在 `/legacy#history` 点选确认，接口再次校验出生分钟后只绑定受限摘要，标记为
非事实参考。辩手过程、裁判细节与逐年结论不回灌，也不能用历史参考验证自身。大运、神煞与流年
仍由每次问事的既有确定性/研究流水线重新计算。

- 用户可见文案受红线词扫描约束（`make redline` 覆盖本目录）：大陆版禁用词见 `infra/compliance/redline-words.txt`，论断一律概率化措辞。
- 结果页/报告/订阅接口的响应文案必须包含免责声明字段（compliance-auditor 检查项）。
- 未成年人拦截与危机识别转介属于本层强制路径，接口设计时预留。
- 原始出生信息与城市只进入本机排盘/存储；运行态模型只接收命盘结构、行业/职业和经过去标识的必要问题，不发送基本盘名称、精确地址、联系方式或账号标识。
