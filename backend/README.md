# backend（FastAPI 应用层）

FastAPI 同时提供原研究接口与 `/api/app/*` 手机 App 闭环：基本盘、问事任务、不可变预测快照、
只增复盘和按类别/周期/算法/模型/规则版本统计。App 数据使用 Python 标准库 SQLite（WAL +
busy timeout + 乐观锁）；旧 `predictions.jsonl` 启动时幂等迁移，不删除或回写旧数据。

基本盘可保存本人确认的高级研究事实并独立版本化。`research-candidates` 读取旧档案中本人录入的
既成事实，并只列出与当前基本盘出生分钟一致的历史研究记录。事实须在 App 编辑页检查并保存；
历史研究须由本人在 `/legacy#history` 点选确认，接口再次校验出生分钟后只绑定受限摘要，标记为
非事实参考。辩手过程、裁判细节与逐年结论不回灌，也不能用历史参考验证自身。大运、神煞与流年
仍由每次问事的既有确定性/研究流水线重新计算。

App 的所有方向性问事固定使用 `D3J`：Claude/子平、Gemini/旺衰、DeepSeek/调候先独立分析，之后
交叉质证并轮换盲评。后端会校验三个角色、三个供应商、三个流派和每方至少一条观点；任一项缺失
即 fail closed，不锁定单方预测。不可变快照同时保存三方观点、盲评摘要和未决分歧，供结果页展示
与以后审计。旧 `S1` 实验臂仅为研究基线保留，不再作为 App 用户入口。

App 问事另有“原问题直答”闸门：基础会诊完成后，三家分别复用既有追问协议回答用户原句，再对
三份直接答案匿名盲评。任务/经营问题若同时给出当前值、目标值和剩余天数，后端先做确定性缺口、
日均要求、完成率与所需增幅计算，再交给三家判断现实条件。三方只谈多年运势而不回答原问题、
缺少任务主题、或文本中出现可识别的十神五行/生克矛盾时，任务失败且不锁定预测。算法版本从
`app-forecast-compose-v1.4.0` 起保存 `computed_metrics` 和三份直接答案；旧记录不作新版直答样本。

- 用户可见文案受红线词扫描约束（`make redline` 覆盖本目录）：大陆版禁用词见 `infra/compliance/redline-words.txt`，论断一律概率化措辞。
- 结果页/报告/订阅接口的响应文案必须包含免责声明字段（compliance-auditor 检查项）。
- 未成年人拦截与危机识别转介属于本层强制路径，接口设计时预留。
- 原始出生信息与城市只进入本机排盘/存储；运行态模型只接收命盘结构、行业/职业和经过去标识的必要问题，不发送基本盘名称、精确地址、联系方式或账号标识。

## 可选的火火大脑资料

正式 App 通过设备安全会话自动连接并绑定明确公司/项目范围，问事页可预览资料；仅手动编辑、逐条确认的L1/L2摘要进入
三方材料。L3/L4流水只供受保护查看，原文不存入App数据库、不外发模型。确认十分钟内有效且仅用一次。

App与独立出口进程分别注入同一 `HUOHUO_EXPORT_TOKEN`；后端仍保留独立的
`SANJIAN_BRAIN_ACCESS_TOKEN` 供受控运维兼容，但不再发送给浏览器。生产运行必须设置
`SANJIAN_REQUIRE_DEVICE_AUTH=1` 和仅由服务进程可读的 `SANJIAN_DEVICE_TOKEN_FILE`：原生 App
在导航请求中完成一次设备令牌交换，后端只下发 HttpOnly、Secure、SameSite=Strict 会话 Cookie，
以后同设备无感调用。设备令牌、会话值和大脑访问口令均不进入页面 JavaScript、本机离线缓存或响应正文。
App必须单worker运行；缺配置时功能关闭，
不可自动导入真实资料。真实PostgreSQL权限、数据口径和发布仍须本人签署，见
[只读接入RFC](../docs/specs/rfc-0003-brain-readonly.md)与[验证清单](../docs/reviews/decision-desk-p2-verification.md)。

仅合成回归运行 `make test-backend`：使用带哈希的固定依赖，同时执行App及出口测试，不读取.env、
不访问正式数据库或云模型。不要为测试运行真实服务启动命令。
