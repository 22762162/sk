# web（L5 手机优先 PWA + 高级研究页）

- `/`：可安装 PWA，底部导航为“首页、问事、记录、我的”。Service Worker 只缓存 App 壳，
  联网时优先更新壳文件、断网时回退缓存；私密 API 响应不进入 Cache Storage，离线查看由当前
  浏览器的私有缓存承担。
- `/legacy`：保留原排盘、三模型会诊、流月、合盘与档案研究页，既有能力不改接口。
- App 首页明确展示 Claude/子平、GPT/旺衰、DeepSeek/调候三方协议，并提供今日、本月、择时、
  关系/合盘、命中率和本机备份入口。需要方向判断的入口统一进入三方问事；今日干支、命中率与
  备份状态属于确定性/运维信息，不冒充 AI 判断。
- 预测结果先展示原问题的确定性指标（若可计算），再并列展示三方直接答案和盲评汇总；新版快照
  缺少任一角色、答非所问或基础十神/生克校验失败时，后端拒绝生成。旧版只有命盘泛论而没有
  “三方直接回答原问题”证据的记录会显示警示，不再把旧结论冒充可行动答案。App 不再自动请求
  单模型“今日解读”，旧 `S1` 快捷按钮也不再对用户显示。
- “我的 → 编辑基本盘”可从高级研究载入本人录入的既成事实；载入内容须人工检查并保存，
  后续问事才会引用。也可打开高级研究历史记录，点选与当前基本盘出生分钟一致的记录并明确确认，
  将其受限摘要绑定为“历史参考”。历史参考不算现实事实，不能验证自身；跨人记录会被后端拒绝。
- 高级研究历史页的“绑定到 App”使用页面内二次点击确认和可见状态，不依赖原生 WebView 可能
  不显示的 JavaScript 弹窗；绑定后仍须返回 App 检查研究版本。
- 离线模式只允许查看最近缓存的基本盘和预测快照；问事与复盘写入必须联网，不做假成功。

## 最小部署约束

本机用 `make v1-serve` 后访问 `http://127.0.0.1:8788`，localhost 环境可直接注册 Service Worker。
私有 VPS 必须使用 HTTPS，并让页面、`/api/*`、`/manifest.webmanifest` 与 `/sw.js` 保持同源；反向代理
不要缓存 `/api/*`，且 `/sw.js` 不应设置长期缓存。项目仍按 DESIGN 定位仅供本人使用；若跨设备访问，
须在反向代理层加认证，不能直接暴露公网。

本机私有数据在 `consult-engine/appdata/sanjian-app.sqlite3`，旧版 `predictions/`、`records/`、
`dossier/` 保持原位。以上路径均已 gitignore；迁移前可停服务后整体备份 `consult-engine/appdata/`。
